# TC-12: Unit tests for arena + gamification API routes

## Scope
Write unit tests for:
- `src/app/api/arena/*` (challenges, streak, claims, reactions, progress, season)
- `src/app/api/gamification/*` (XP, levels, badges, leaderboard)

## Test file
`src/__tests__/api/arena.test.ts`

## Requirements
- Mock DB pool, auth session
- Test: list challenges, claim reward, streak calculation, XP award, leaderboard query, level-up logic, reaction posting, season active/inactive
- Min 10 test cases
- Note: some arena-reactions tests already exist in `__tests__/arena-reactions.test.ts` — don't duplicate, extend

## Quality gates
1. `npx jest src/__tests__/api/arena.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
