# mc-08: Policy Tier Templates

## Objective
Create default policy tier templates that define what each plan level gets.

## Requirements
1. Create `src/lib/policy/templates.ts` with predefined tiers:
   - `free`: 1 agent, 3 models, 100MB storage, 100 API calls/day, no custom tools, 1 team member
   - `pro`: 5 agents, all models, 5GB storage, 10000 API calls/day, custom tools enabled, 10 team members
   - `enterprise`: unlimited everything
2. Export `getDefaultPolicy(tierName: string): Policy` function
3. Export `TIER_NAMES` constant array
4. Templates must conform to the Zod schemas from mc-07
5. Write tests in `src/__tests__/lib/policy-templates.test.ts`

## Dependencies
- Uses types from `src/lib/policy/schema.ts` (mc-07)
