# mc-06: Admin API — list tenants endpoint

Build the admin tenants API endpoint.

Create:
- `src/app/api/admin/tenants/route.ts` — GET returns all tenants with user counts

Auth: require session with `tenantId === 1`. Return 401 if no session, 403 if not admin.
Response: JSON array of `{ id, name, slug, plan, createdAt, userCount }`.
Use `src/db/schema.ts` → `tenants` table, count from `users`.

Also create test:
- `src/__tests__/api/admin-tenants.test.ts`

Reference `src/__tests__/api/activity.test.ts` for the mocking pattern.

Test cases:
- GET returns tenant list with user counts
- GET without session returns 401
- GET with non-admin session returns 403

Run: `npx jest src/__tests__/api/admin-tenants.test.ts --ci`
All tests must pass. Commit when done.
