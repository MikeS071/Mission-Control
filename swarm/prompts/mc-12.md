# mc-12: Policy Editor UI + Admin Tab Migration

## Objective
Create the policy editor page in the admin section AND migrate the dashboard admin tab.

## Requirements

### Policy Editor
1. Create `src/app/admin/policies/page.tsx` — list all tenant policies with tier badges
2. Create `src/app/admin/policies/[tenantId]/page.tsx` — edit a tenant's policy:
   - Show current tier with dropdown to change
   - Show all rules in editable form (toggle for booleans, number inputs for limits)
   - Custom override toggle per rule
   - Save button → calls PUT API
   - Reset to defaults button → calls POST reset API
   - Show audit log history at bottom
3. Add "Policies" link to AdminSidebar

### Admin Tab Migration
4. Move the ProvisioningPanel from dashboard admin tab to `src/app/admin/provisioning/page.tsx`
5. In dashboard `page.tsx`: replace the "🔧 Admin" tab content with a link/button to `/admin`
6. Add "Provisioning" link to AdminSidebar

## Dependencies
- Uses tenant detail page (mc-04), policy API (mc-11)
- Existing ProvisioningPanel at `src/components/ProvisioningPanel.tsx` (or similar)
