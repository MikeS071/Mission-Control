# mc-17: Budget Enforcement

## Objective
Check tenant budget before forwarding requests to AiPipe. Reject if over budget.

## Requirements
1. `src/lib/usage/budget.ts`:
   - `checkBudget(tenantId: number): Promise<{ allowed: boolean; remaining: number; limit: number; period: string }>`
   - Read tenant's policy (from P2 policy system) for `api_calls_per_day` or budget limit
   - Query `usage_summary` for current period
   - Return allowed/denied with remaining budget
2. Budget types (from policy):
   - `api_calls_per_day` (number) — request count limit
   - Future: `budget_usd_per_month` (add to policy feature keys)
3. Wire into AiPipe proxy routes BEFORE forwarding:
   - If not allowed: return 429 with `{ error: "Budget exceeded", remaining: 0, limit: N, resetsAt: "..." }`
   - Include `X-Budget-Remaining` and `X-Budget-Limit` response headers on every response
4. Add `budget_usd_per_month` to `POLICY_FEATURE_KEYS` in `src/lib/policy/schema.ts`
5. Tests: under budget → allowed, over budget → 429, no policy → unlimited (default)

## Dependencies
- mc-15 (usage ledger), mc-16 (metering populates the ledger)
