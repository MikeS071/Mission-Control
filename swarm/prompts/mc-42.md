# mc-42: API Rate Limiting

## Objective
Add rate limiting to API routes to prevent abuse.

## Requirements
1. `src/lib/rateLimit.ts`:
   - `createRateLimiter(opts: { windowMs, maxRequests, keyFn? }): RateLimiter`
   - `RateLimiter.check(key: string): { allowed: boolean, remaining: number, resetAt: Date }`
   - In-memory sliding window (Map-based, no Redis dependency)
   - Auto-cleanup expired windows every 5 minutes
2. `src/middleware.ts` or wrapper function:
   - Apply rate limit to all `/api/` routes
   - Default: 100 requests per minute per IP
   - Admin routes: 200 per minute
   - Return 429 with `Retry-After` header when exceeded
3. Response headers: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`
4. Tests in `src/__tests__/lib/rate-limit.test.ts`

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
