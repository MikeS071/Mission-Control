# mc-10: Policy Eval Helpers

## Objective
Create functions to evaluate policy rules against usage data.

## Requirements
1. Create `src/lib/policy/eval.ts` with:
   - `checkLimit(policy: Policy, feature: FeatureKey, currentUsage: number): { allowed: boolean; limit: number | 'unlimited'; remaining: number | 'unlimited' }`
   - `getEffectiveRules(policy: Policy): PolicyRule[]` — merges tier defaults with custom overrides
   - `isFeatureEnabled(policy: Policy, feature: FeatureKey): boolean`
2. Handle edge cases: missing rules default to denied, unlimited always passes
3. Write tests in `src/__tests__/lib/policy-eval.test.ts` — cover all feature keys, all limit types, override scenarios

## Dependencies
- Uses schema from mc-07, DB from mc-09
