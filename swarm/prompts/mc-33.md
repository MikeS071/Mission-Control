# mc-33: Deployment Status Panel

## Objective
Admin panel showing current deployment info — git SHA, build time, version.

## Requirements
1. `src/app/admin/system/deployment/page.tsx`:
   - Shows: current git SHA, build timestamp, Node version, uptime
   - Environment indicator (dev/staging/prod)
   - Link to GitHub commit
2. `src/app/api/admin/system/deployment/route.ts`:
   - `GET` — returns deployment info
   - Reads from env vars: GIT_SHA, BUILD_TIME, NODE_ENV, UPTIME
3. `src/lib/admin/deployment.ts`:
   - `getDeploymentInfo(): DeploymentInfo`
   - `DeploymentInfo { gitSha, buildTime, nodeVersion, uptime, environment }`
4. Tests in `src/__tests__/api/deployment.test.ts`

## Dependencies
- mc-01 (admin layout)

## Reference
