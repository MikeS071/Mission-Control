# mc-20: Pricing Rates Config

## Objective
MC-managed pricing rates per model/tier. AiPipe provides base costs; MC applies tenant-facing markup.

## Requirements
1. `src/lib/usage/pricing.ts`:
   - `PricingRate { modelPattern: string, markupPercent: number, flatFeePerRequest: number }`
   - `getTenantCost(baseCostUsd: number, model: string, tenantPlan: string): number`
   - Logic: `tenantCost = baseCostUsd * (1 + markupPercent/100) + flatFeePerRequest`
   - Markup varies by plan: free=50%, pro=20%, team=0% (configurable)
2. Config in `src/lib/usage/pricing-config.ts` (NOT hardcoded in function):
   ```typescript
   export const PRICING_CONFIG = {
     defaultMarkup: { free: 50, pro: 20, team: 0 },
     modelOverrides: {
       'gpt-4o-mini': { free: 30, pro: 10, team: 0 },
     },
     flatFeePerRequest: 0, // USD
   } as const;
   ```
3. Wire into mc-16 metering: store both `costUsd` (AiPipe base) and `tenantCostUsd` (with markup) in ledger
4. Add `tenantCostUsd` column to `usage_ledger` schema (nullable, for backwards compat)
5. Tests: markup calculation, plan-based rates, model override, zero markup for team

## Key Principle
AiPipe defines base model costs. MC defines business pricing (markup). They are separate concerns.

## Dependencies
- mc-16 (metering middleware — pricing plugs into the recording step)
