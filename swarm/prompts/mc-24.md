# mc-24: Kanban Empty Board Suggestions

## Objective
When a kanban board has no tasks, show helpful suggestions/templates to get started.

## Requirements
1. `src/lib/kanban/suggestions.ts`:
   - `getEmptyBoardSuggestions(tenantPlan: string): Suggestion[]`
   - Suggestion type: `{ title: string, description: string, templateTasks: { title: string, status: string }[] }`
   - At least 3 built-in templates: "Getting Started", "Feature Sprint", "Bug Triage"
2. `src/components/EmptyBoardSuggestions.tsx`:
   - Renders when task list is empty
   - Card layout with "Use Template" button per suggestion
   - Clicking creates the template tasks via existing task API
3. Tests in `src/__tests__/lib/suggestions.test.ts`
4. Component tests for EmptyBoardSuggestions

## Reference
- Dashboard page: `src/app/dashboard/page.tsx`
- Task API: `src/app/api/tasks/route.ts`
- Test pattern: `src/__tests__/api/activity.test.ts`
