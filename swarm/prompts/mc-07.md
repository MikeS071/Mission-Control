# mc-07: Policy Schema (Zod + types)

## Objective
Create the policy type system for Mission Control's tenant policy engine.

## Requirements
1. Create `src/lib/policy/schema.ts` with Zod schemas for:
   - `PolicyRule` — individual rule (feature key, limit type, limit value, enabled boolean)
   - `PolicyTier` — named tier with array of rules (e.g., "free", "pro", "enterprise")
   - `Policy` — full policy document (tenant ID, tier name, custom overrides, created/updated timestamps)
2. Export TypeScript types inferred from Zod schemas
3. Feature keys should be an enum/union: `agents`, `models`, `storage_mb`, `api_calls_per_day`, `custom_tools`, `team_members`
4. Limit types: `boolean`, `number`, `unlimited`
5. Add validation helpers: `validatePolicy()`, `validateRule()`
6. Write tests in `src/__tests__/lib/policy-schema.test.ts`

## Constraints
- No DB access in this ticket — pure types and validation
- Reference existing test patterns in `src/__tests__/lib/auth.test.ts`
