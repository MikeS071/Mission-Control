# mc-05: Admin API — list users endpoint

Build the admin users API endpoint.

Create:
- `src/app/api/admin/users/route.ts` — GET returns all users with tenant info

Auth: require session with `tenantId === 1`. Return 401 if no session, 403 if not admin.
Response: JSON array of `{ id, email, tenantId, tenantName, createdAt, lastLogin }`.
Use `src/db/schema.ts` → `users` table, join with `tenants`.

Also create test:
- `src/__tests__/api/admin-users.test.ts`

Reference `src/__tests__/api/activity.test.ts` for the mocking pattern.

Test cases:
- GET returns user list
- GET without session returns 401
- GET with non-admin session returns 403

Run: `npx jest src/__tests__/api/admin-users.test.ts --ci`
All tests must pass. Commit when done.
