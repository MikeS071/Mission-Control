# TC-05: Unit tests for utility lib

## Scope
Write unit tests for utility/helper library files:
- `src/lib/utils.ts` — general utilities
- `src/lib/markdown.ts` — markdown parsing/rendering helpers
- `src/lib/source.ts` — source tracking
- `src/lib/prd-files.ts` — PRD file operations
- `src/lib/telegram-ingress.ts` — Telegram message ingestion

## Test file
`src/__tests__/lib/utils.test.ts`

## Requirements
- These are mostly pure functions — minimal mocking needed
- Test: markdown rendering edge cases, utility function boundaries, telegram message parsing, source URL extraction
- Min 10 test cases

## Quality gates
1. `npx jest src/__tests__/lib/utils.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
