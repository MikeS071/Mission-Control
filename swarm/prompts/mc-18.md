# mc-18: Usage Dashboard API

## Objective
API endpoints serving usage data for the tenant dashboard.

## Requirements
1. `GET /api/usage/summary?period=daily|monthly&from=ISO&to=ISO`
   - Returns usage_summary rows for authenticated tenant
   - Default: last 30 days daily
2. `GET /api/usage/breakdown?groupBy=model|provider&from=ISO&to=ISO`
   - Aggregates from usage_ledger: total tokens, cost, requests grouped by model or provider
3. `GET /api/usage/savings`
   - Total saved vs hypothetical (from usage_summary totalSavedUsd)
   - Savings percentage
4. All endpoints: auth required, tenant-scoped (read tenantId from session)
5. Tests: each endpoint returns correct data, tenant isolation verified

## Dependencies
- mc-15 (schema)
