# TC-08: Unit tests for task API routes

## Scope
Write unit tests for all task API routes under `src/app/api/tasks/`:
- List the routes by reading the directory
- Cover: CRUD, status transitions, comments, assignments, filtering

## Test file
`src/__tests__/api/tasks.test.ts`

## Requirements
- Mock DB pool, auth session
- Test: create task, update task, delete task, list tasks with filters, add comment, assign user, invalid task ID, unauthorized access
- Min 10 test cases

## Quality gates
1. `npx jest src/__tests__/api/tasks.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
