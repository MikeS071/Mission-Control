# mc-13: Policy Audit Log

## Objective
Create a dedicated audit log viewer in admin.

## Requirements
1. Create `GET /api/admin/audit-log` — paginated list of all policy changes across tenants
   - Query params: `?tenantId=X` (optional filter), `?page=1&limit=20`
   - Returns: tenant name, changed_by user, old/new rules diff summary, reason, timestamp
2. Create `src/app/admin/audit-log/page.tsx` — table view with:
   - Filters by tenant
   - Expandable rows showing full old/new JSON diff
   - Pagination
3. Add "Audit Log" link to AdminSidebar
4. Write tests in `src/__tests__/api/admin-audit-log.test.ts`

## Dependencies
- Uses policy API (mc-11) which writes audit entries
