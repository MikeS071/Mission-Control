# mc-34: Error Tracking + Alerts

## Objective
Track application errors and surface recent errors to admin with alert thresholds.

## Requirements
1. `src/lib/admin/errorTracker.ts`:
   - `trackError(error: { message, stack?, source, severity: 'low'|'medium'|'high'|'critical' }): Promise<void>`
   - `getRecentErrors(opts: { severity?, limit?, since? }): Promise<TrackedError[]>`
   - `getErrorRate(windowMinutes: number): Promise<{ total, perMinute, bySeverity }>`
   - Store in DB: error_log (id, message, stack, source, severity, created_at)
2. `src/app/api/admin/system/errors/route.ts`:
   - `GET ?severity=&limit=&since=` — list errors
   - `GET /rate?window=60` — error rate stats
3. `src/app/admin/system/errors/page.tsx`:
   - Error list with severity badges
   - Error rate chart (simple bar chart, last 24h by hour)
   - Alert banner if error rate > threshold
4. Tests in `src/__tests__/api/error-tracker.test.ts`

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
