# mc-22: Kanban Bot Activation Triggers

## Objective
When a kanban task changes status (created, moved, completed), emit events that downstream automation (bot, notifications) can consume.

## Requirements
1. `src/lib/kanbanTrigger.ts` — extend or create:
   - `emitTaskEvent(taskId: string, event: 'created' | 'moved' | 'completed' | 'overdue', metadata?: Record<string, any>): Promise<void>`
   - Events stored in `task_events` table (or activity log pattern from existing code)
   - Include: taskId, event type, timestamp, tenantId, userId
2. API route `src/app/api/tasks/events/route.ts`:
   - `GET` — list recent events for tenant (last 50, filterable by type)
   - `POST` — create manual event (admin use)
3. Hook into existing task CRUD (`src/app/api/tasks/route.ts`, `src/app/api/tasks/[id]/route.ts`):
   - On task create → emit `created`
   - On task status change → emit `moved`
   - On task marked done → emit `completed`
4. Tests in `src/__tests__/api/kanban-triggers.test.ts`

## Reference
- Existing task routes: `src/app/api/tasks/route.ts`
- Existing kanban trigger: `src/lib/kanbanTrigger.ts`
- Test pattern: `src/__tests__/api/activity.test.ts`
