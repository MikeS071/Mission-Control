# mc-31: System Health Dashboard

## Objective
Admin page showing system health overview — services, memory, uptime.

## Requirements
1. `src/app/admin/system/page.tsx`:
   - Cards showing: DB connection (pool stats), AiPipe health, CF Tunnel status
   - Auto-refresh every 30s
   - Green/yellow/red indicators per service
2. `src/app/api/admin/system/health/route.ts`:
   - `GET` — returns health check for each service
   - DB: run `SELECT 1` with timeout
   - AiPipe: `GET http://127.0.0.1:8082/healthz`
   - Returns `{ services: { name, status, latencyMs, details }[] }`
3. `src/lib/admin/healthCheck.ts`:
   - `checkHealth(): Promise<HealthReport>`
   - Parallel checks with 5s timeout each
4. Tests in `src/__tests__/api/system-health.test.ts`

## Reference
- Admin auth: `src/lib/admin-auth.ts`
- Test pattern: `src/__tests__/api/activity.test.ts`
