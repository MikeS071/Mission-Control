# TC-07: Unit tests for chat API routes

## Scope
Write unit tests for all chat API routes under `src/app/api/chat/`:
- List the routes by reading the directory
- Cover: send message, get history, create/list threads, reactions, typing indicators, SSE stream

## Test file
`src/__tests__/api/chat.test.ts`

## Requirements
- Mock DB pool, auth session (getServerSession), WebSocket
- Test: send message (authenticated + unauthenticated), get history (with pagination), thread CRUD, reaction toggle, invalid inputs, rate limiting if present
- Min 10 test cases

## Quality gates
1. `npx jest src/__tests__/api/chat.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
