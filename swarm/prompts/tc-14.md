# TC-14: Unit tests for gateway + AiPipe API routes

## Scope
Write unit tests for:
- `src/app/api/gateway/*` (config, status, connect)
- `src/app/api/aipipe/*` (proxy/chat, proxy/messages, health, stats)

## Test file
`src/__tests__/api/gateway-aipipe.test.ts`

## Requirements
- Mock fetch (upstream proxy calls), DB pool, auth session
- Test: AiPipe proxy forwards correctly, health endpoint returns status, stats aggregation, gateway config CRUD, unauthorized proxy blocked, malformed request handling
- Min 8 test cases

## Quality gates
1. `npx jest src/__tests__/api/gateway-aipipe.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
