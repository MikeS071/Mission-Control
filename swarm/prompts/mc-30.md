# mc-30: Content Hero Image Preview

## Objective
Display hero image preview on content detail page, with upload capability.

## Requirements
1. `src/components/HeroImagePreview.tsx`:
   - Shows hero image if URL exists (from content_items.hero_image_url column)
   - Placeholder when no image
   - File upload input that stores to local `/public/images/<slug>.png`
2. `src/app/api/admin/content/[slug]/hero/route.ts`:
   - `POST` (multipart) — upload hero image, save to public/images/, update content_items.hero_image_url
   - `DELETE` — remove hero image
3. Add hero_image_url column to content_items table (nullable string)
4. Integrate into content detail page (mc-27)
5. Tests in `src/__tests__/api/content-hero.test.ts`

## Dependencies
- mc-27 (content detail page)

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
