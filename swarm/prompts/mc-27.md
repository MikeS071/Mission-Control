# mc-27: Content Detail + Editor Page

## Objective
Detail page for viewing and editing a single content item with markdown editor.

## Requirements
1. `src/app/admin/content/[slug]/page.tsx`:
   - Title field (editable)
   - Summary field (editable, textarea)
   - Markdown editor for content body (use textarea with preview toggle)
   - Status badge (draft/qa/published)
   - Save button (PATCH to API)
   - Delete button with confirmation modal
2. `src/app/api/admin/content/[slug]/route.ts`:
   - `GET` — fetch single content item by slug
   - `PATCH` — update title, summary, content_md, status
   - `DELETE` — soft delete (set status='deleted')
3. Tests in `src/__tests__/api/content-detail.test.ts`

## Dependencies
- mc-26 (content list + content_items table)

## Reference
- Admin auth: `src/lib/admin-auth.ts`
- Test pattern: `src/__tests__/api/activity.test.ts`
