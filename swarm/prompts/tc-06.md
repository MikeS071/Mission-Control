# TC-06: Unit tests for auth API routes

## Scope
Write unit tests for authentication API routes:
- `src/app/api/auth/[...nextauth]/route.ts`
- `src/app/api/auth/forgot-password/route.ts`
- `src/app/api/auth/reset-password/route.ts`
- `src/app/api/signup/route.ts`

## Test file
`src/__tests__/api/auth.test.ts`

## Requirements
- Mock NextAuth, DB pool, bcrypt, email sending (Resend)
- Test: signup with valid/invalid data, duplicate email, password reset flow (request + redeem), forgot password email trigger, NextAuth route handler existence
- Min 10 test cases
- Use `NextRequest` from `next/server` to construct test requests

## Quality gates
1. `npx jest src/__tests__/api/auth.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
