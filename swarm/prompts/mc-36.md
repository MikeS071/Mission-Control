# mc-36: Migration Config Schema

## Objective
Define the schema and types for tenant data migration configuration.

## Requirements
1. `src/lib/migration/schema.ts`:
   - `MigrationConfig { sourceType: 'json'|'csv'|'api', targetTenantId, mappings, options }`
   - `MigrationMapping { sourceField, targetField, transform?: 'direct'|'date'|'number'|'boolean' }`
   - `MigrationStatus { id, config, state: 'pending'|'running'|'completed'|'failed', progress, errors, startedAt, completedAt }`
   - `validateMigrationConfig(config: MigrationConfig): { valid: boolean, errors: string[] }`
2. DB: migration_jobs table (id, tenant_id, config_json, state, progress_pct, error_log, started_at, completed_at)
3. `src/app/api/admin/migrations/route.ts`:
   - `GET` — list migration jobs for tenant
   - `POST` — create new migration job (validates config)
4. Tests in `src/__tests__/lib/migration-schema.test.ts`

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
