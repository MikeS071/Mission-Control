# TC-02: Unit tests for chat lib

## Scope
Write unit tests for chat library files:
- `src/lib/chat-threads.ts` — thread CRUD, listing, filtering
- `src/lib/chat-system.ts` — system message handling, chat state
- `src/lib/openclaw-chat.ts` — OpenClaw chat integration, message relay

## Test file
`src/__tests__/lib/chat.test.ts`

## Requirements
- Mock DB pool, WebSocket connections, external API calls
- Test: create thread, list threads, send message, message history, system messages, error handling for disconnected state
- Min 8 test cases
- No real DB or WebSocket connections

## Quality gates
1. `npx jest src/__tests__/lib/chat.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
