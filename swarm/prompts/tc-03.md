# TC-03: Unit tests for gateway lib

## Scope
Write unit tests for gateway/WebSocket library files:
- `src/lib/gateway.ts` — gateway connection, status checking
- `src/lib/openclaw-gateway-cli.ts` — CLI command relay
- `src/lib/ws-manager.ts` — WebSocket connection management, reconnect logic
- `src/lib/openclaw-ws-client.ts` — WebSocket client wrapper

## Test file
`src/__tests__/lib/gateway.test.ts`

## Requirements
- Mock WebSocket, fetch, timers
- Test: connection establish, heartbeat send/receive, reconnect on disconnect, CLI command formatting, status check success/failure, connection timeout
- Min 8 test cases

## Quality gates
1. `npx jest src/__tests__/lib/gateway.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
