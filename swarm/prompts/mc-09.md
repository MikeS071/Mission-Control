# mc-09: Policy DB Migration

## Objective
Add policy tables to the database.

## Requirements
1. Create migration in `src/db/migrations/` (next sequence number)
2. Table `policies`:
   - `id` serial primary key
   - `tenant_id` integer references tenants(id) unique
   - `tier` text not null default 'free'
   - `rules` jsonb not null (stores the full policy rules array)
   - `custom_overrides` jsonb (nullable, for per-tenant overrides)
   - `created_at` timestamptz default now()
   - `updated_at` timestamptz default now()
3. Table `policy_audit_log`:
   - `id` serial primary key
   - `tenant_id` integer references tenants(id)
   - `changed_by` integer references users(id)
   - `old_rules` jsonb
   - `new_rules` jsonb
   - `change_reason` text
   - `created_at` timestamptz default now()
4. Add Drizzle schema definitions in `src/db/schema.ts`
5. Write schema test in `src/__tests__/db/policy-schema.test.ts`

## Dependencies
- Uses types from `src/lib/policy/schema.ts` (mc-07) for JSONB structure
