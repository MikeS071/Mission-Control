# TC-21: Activity route tests

Write comprehensive unit tests for these API routes:
- `src/app/api/activity/comments/route.ts`
- `src/app/api/activity/events/route.ts`
- `src/app/api/activity/reactions/route.ts`
- `src/app/api/activity/drain/route.ts`
- `src/app/api/activity/stream/route.ts`

Tests go in `src/__tests__/api/activity.test.ts`.

Mock all DB calls (drizzle), mock `headers()` for tenant context. Test:
- GET/POST handlers with valid input
- Missing/invalid tenant ID returns 401/400
- Edge cases (empty results, missing fields)

Run `npx jest src/__tests__/api/activity.test.ts --ci` — all tests must pass.
