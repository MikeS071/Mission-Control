# mc-26: Content List Page

## Objective
Admin page listing all content items managed by the ContentAI pipeline.

## Requirements
1. `src/app/admin/content/page.tsx`:
   - Table showing: title, slug, status (draft/qa/published), created date, last updated
   - Filter by status (all/draft/qa/published)
   - Search by title/slug
   - Link to detail page per item
   - "New Content" button (navigates to detail page in create mode)
2. `src/app/api/admin/content/route.ts`:
   - `GET` — list content items for tenant, supports `?status=` and `?q=` query params
   - Returns: `{ items: ContentItem[], total: number }`
3. `src/lib/content.ts`:
   - `ContentItem { id, title, slug, status, summary, createdAt, updatedAt }`
   - `listContent(tenantId: number, opts?: { status?: string, query?: string }): Promise<ContentItem[]>`
4. DB: content_items table if not exists (id, tenant_id, title, slug, status, summary, content_md, created_at, updated_at)
5. Tests in `src/__tests__/api/content-list.test.ts`

## Reference
- Admin auth: `src/lib/admin-auth.ts`
- Admin layout pattern: `src/app/admin/provisioning/page.tsx`
- Test pattern: `src/__tests__/api/activity.test.ts`
