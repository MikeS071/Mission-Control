# mc-21: Usage Alerts

## Objective
Notify tenants when approaching budget limits.

## Requirements
1. `src/lib/usage/alerts.ts`:
   - `checkAlerts(tenantId: number): Promise<Alert[]>`
   - Alert thresholds: 75%, 90%, 100% of budget
   - Alert types: 'budget_warning' | 'budget_critical' | 'budget_exceeded'
2. Check on every metering write (mc-16): after recording usage, check if threshold crossed
3. Store alerts in DB:
   ```typescript
   export const usageAlerts = pgTable('usage_alerts', {
     id: serial('id').primaryKey(),
     tenantId: integer('tenant_id').notNull().references(() => tenants.id),
     alertType: text('alert_type').notNull(),
     threshold: integer('threshold').notNull(), // 75, 90, 100
     message: text('message').notNull(),
     acknowledged: boolean('acknowledged').notNull().default(false),
     createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
   });
   ```
4. `GET /api/usage/alerts` — returns unacknowledged alerts for tenant
5. `POST /api/usage/alerts/:id/ack` — acknowledge alert
6. Show alert banner on dashboard when unacknowledged alerts exist
7. Don't spam: only create alert once per threshold per period
8. Tests: threshold detection, no duplicate alerts, acknowledge works

## Dependencies
- mc-17 (budget enforcement — knows the limits)
