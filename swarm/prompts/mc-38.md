# mc-38: Migration Data Export

## Objective
Export tenant data for backup or migration to another system.

## Requirements
1. `src/lib/migration/export.ts`:
   - `exportTenantData(tenantId: number, tables?: string[]): Promise<ExportResult>`
   - `ExportResult { tables: { name, rowCount, data: any[] }[], exportedAt: string }`
   - Default exports: tasks, content_items, activity_log
   - Strips internal IDs, converts timestamps to ISO
2. `src/app/api/admin/migrations/export/route.ts`:
   - `POST { tenantId, tables? }` — returns JSON export
   - Response as downloadable JSON file (Content-Disposition header)
3. Tests in `src/__tests__/lib/migration-export.test.ts`

## Dependencies
- mc-36 (migration schema)

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
