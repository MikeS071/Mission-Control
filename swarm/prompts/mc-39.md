# mc-39: Migration UI Wizard

## Objective
Step-by-step wizard UI for configuring and running data migrations.

## Requirements
1. `src/app/admin/migrations/page.tsx`:
   - List existing migration jobs with status
   - "New Migration" button → wizard
2. `src/components/MigrationWizard.tsx`:
   - Step 1: Select source type (JSON upload, CSV upload)
   - Step 2: Upload file, preview first 5 rows
   - Step 3: Map fields (source → target), auto-detect where possible
   - Step 4: Run preflight check, show warnings/errors
   - Step 5: Execute or cancel
   - Progress bar during execution
3. Tests in `src/__tests__/components/migration-wizard.test.tsx`

## Dependencies
- mc-37 (preflight API), mc-38 (export)

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
