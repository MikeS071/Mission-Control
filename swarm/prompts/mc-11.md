# mc-11: Policy Admin API

## Objective
Create API endpoints for admin policy management.

## Requirements
1. `GET /api/admin/policies` — list all tenant policies (admin only, tenantId === 1)
2. `GET /api/admin/policies/[tenantId]` — get specific tenant's policy
3. `PUT /api/admin/policies/[tenantId]` — update tenant's policy (tier change or custom overrides)
4. `POST /api/admin/policies/[tenantId]/reset` — reset to tier defaults
5. All endpoints require admin auth (tenantId === 1 check)
6. PUT endpoint must:
   - Validate input against Zod schema
   - Write audit log entry with old/new rules and change reason
   - Return updated policy
7. Write tests in `src/__tests__/api/admin-policies.test.ts`

## Dependencies
- Uses schema (mc-07), templates (mc-08), DB (mc-09)
- Follow existing API patterns in `src/app/api/admin/users/route.ts`
