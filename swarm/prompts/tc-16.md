# TC-16: Unit tests for DB schema

## Scope
Write validation tests for `src/db/schema.ts`:
- Verify all table definitions export correctly
- Verify relation definitions are consistent
- Verify type exports match expected shapes

- Min 6 test cases
- No DB connection needed — just import validation

## Quality gates

2. `npx tsc --noEmit` — no type errors
