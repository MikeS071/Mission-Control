# mc-28: Content Publish Action

## Objective
Publish action that transitions content from draft/qa to published status.

## Requirements
1. `src/lib/content/publish.ts`:
   - `publishContent(slug: string, tenantId: number): Promise<{ success: boolean, publishedAt: string }>`
   - Validates: content exists, has title + summary + content_md, status is draft or qa
   - Sets status='published', publishedAt=now
   - Returns error if validation fails
2. `src/app/api/admin/content/[slug]/publish/route.ts`:
   - `POST` — trigger publish, returns updated content item
3. UI: Add "Publish" button to content detail page (only shown for draft/qa items)
4. Tests in `src/__tests__/lib/content-publish.test.ts`

## Dependencies
- mc-27 (content detail page + API)

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
