# TC-09: Unit tests for admin API routes

## Scope
Write unit tests for admin API routes under `src/app/api/admin/`:
- List the routes by reading the directory
- Cover: user management, billing admin, model config, tenant management, stats

## Test file
`src/__tests__/api/admin.test.ts`

## Requirements
- Mock DB pool, auth session (must verify isAdmin check)
- Test: admin-only access (non-admin rejected with 403), list users, update user, billing stats, model configuration CRUD
- Min 8 test cases

## Quality gates
1. `npx jest src/__tests__/api/admin.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
