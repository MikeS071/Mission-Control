# mc-29: Content Social Scheduling

## Objective
Schedule social posts (X/LinkedIn) for published content items.

## Requirements
1. `src/lib/content/social.ts`:
   - `SocialPost { platform: 'x' | 'linkedin', text: string, scheduledAt: string, status: 'scheduled' | 'posted' | 'failed' }`
   - `scheduleSocialPost(slug: string, post: Omit<SocialPost, 'status'>): Promise<SocialPost>`
   - `listSocialPosts(slug: string): Promise<SocialPost[]>`
2. DB: content_social_posts table (id, content_item_id, platform, text, scheduled_at, status, posted_at, error)
3. `src/app/api/admin/content/[slug]/social/route.ts`:
   - `GET` — list scheduled posts for content item
   - `POST` — schedule a new post (validate: content must be published)
4. UI section in content detail page: "Social Posts" with list + "Schedule Post" form
5. Tests in `src/__tests__/api/content-social.test.ts`

## Dependencies
- mc-27 (content detail page)

## Reference
- Test pattern: `src/__tests__/api/activity.test.ts`
