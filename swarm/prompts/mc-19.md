# mc-19: Usage Dashboard UI

## Objective
Usage analytics page in the MC dashboard.

## Requirements
1. `src/app/dashboard/usage/page.tsx`
2. Add "Usage" link to dashboard sidebar navigation
3. Charts (use recharts — already in MC deps or add):
   - Daily request volume (bar chart)
   - Daily cost (area chart, with savings gap if data available)
   - Model breakdown (pie chart)
   - Provider breakdown (pie chart)
4. Summary cards at top:
   - Total requests (this month)
   - Total cost (this month)
   - Total saved (this month, with % badge)
   - Budget remaining (if policy has budget limit)
5. Date range picker (7d / 30d / 90d)
6. Data from `/api/usage/summary`, `/api/usage/breakdown`, `/api/usage/savings`
7. Dark theme, consistent with existing MC dashboard styling

## Dependencies
- mc-18 (API endpoints)
