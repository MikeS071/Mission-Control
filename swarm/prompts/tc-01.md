# TC-01: Unit tests for auth lib

## Scope
Write comprehensive unit tests for the authentication library files:
- `src/lib/auth.ts` — NextAuth config, session handling, JWT callbacks, role checks
- `src/lib/auth.config.ts` — auth configuration, provider setup

## Test file
`src/__tests__/lib/auth.test.ts`

## Requirements
- Mock `next-auth` providers, DB pool queries, and bcrypt
- Test: successful login, failed login (wrong password), suspended user blocked, JWT token enrichment with tenantId/isAdmin, session callback populates user fields, OAuth user upsert (new + existing), account linking
- Min 10 test cases covering happy path, error path, edge cases
- Use `jest.mock()` for external deps — no real DB connections
- Follow existing test patterns in `src/__tests__/lib/crypto.test.ts`

## Quality gates
1. `npx jest src/__tests__/lib/auth.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
