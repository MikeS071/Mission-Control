# TC-04: Unit tests for AI lib

## Scope
Write unit tests for AI-related library files:
- `src/lib/prd-ai.ts` — PRD generation, AI-assisted editing
- `src/lib/checklist-ai.ts` — AI checklist generation
- `src/lib/kanbanTrigger.ts` — Kanban automation triggers

## Test file
`src/__tests__/lib/ai.test.ts`

## Requirements
- Mock LLM API calls (fetch), DB queries
- Test: prompt construction, response parsing, error handling for API failures, malformed responses, empty inputs, kanban trigger conditions
- Min 8 test cases

## Quality gates
1. `npx jest src/__tests__/lib/ai.test.ts` — all pass
2. `npx tsc --noEmit` — no type errors
