# mc-25: Provisioning Template Sync

## Objective
Sync provisioning templates (workspace configs) from a source repo/directory so new tenant instances get up-to-date defaults.

## Requirements
1. `src/lib/provisioning/templateSync.ts`:
   - `syncTemplates(sourceDir: string, targetDir: string): Promise<SyncResult>`
   - `SyncResult { synced: string[], skipped: string[], errors: string[] }`
   - Compares file hashes, only copies changed files
   - Supports `.template-ignore` file for exclusions
2. API route `src/app/api/admin/provision/templates/route.ts`:
   - `GET` — list available templates with last-synced timestamp
   - `POST` — trigger sync manually (admin only)
3. Tests in `src/__tests__/lib/template-sync.test.ts`
4. Tests in `src/__tests__/api/provision-templates.test.ts`

## Reference
- Existing provisioning: `src/lib/provisioning.ts`
- Provisioning API: `src/app/api/admin/provision/route.ts`
- Admin auth: `src/lib/admin-auth.ts`
